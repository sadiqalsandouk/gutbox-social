# gutbox-social

Images for GutBox's scheduled Instagram, Facebook and Threads posts, served by GitHub Pages at
`https://sadiqalsandouk.github.io/gutbox-social/social/<post>/<n>.jpg`.

Don't edit here. The source is `public/social` in the gutbox-landing-page repo; its
`sync-social-images` workflow copies that folder here on every push to main.
